# Syed Wasay — 3D Portfolio

A dependency-light, GitHub Pages friendly portfolio built with vanilla HTML/CSS/JS.

## Included
- Responsive modern dark + warm-gold visual system
- CSS 3D hero object and rotating 3D cube
- Lightweight canvas particle depth layer
- Smooth scrolling, reveal transitions and pointer interactions
- Magnetic CTA button
- Project filters + load more
- Your 40+ project data already included
- Services, process, about, stats and contact sections
- WhatsApp, phone, email and Instagram links
- FormSubmit contact form to `wasayweb@gmail.com`
- Accessibility-minded reduced-motion mode
- No build process

## Add your project images
Keep your existing image structure under:
`assets/img/website/...`

The HTML references the exact paths from your supplied project list.

## GitHub Pages
1. Upload the folder contents to your repository.
2. Keep `index.html` at the repository root.
3. Go to Settings → Pages.
4. Select your deployment branch/folder.
5. Open the generated GitHub Pages URL.

## FormSubmit
The form posts to:
`https://formsubmit.co/wasayweb@gmail.com`

On the first submission, FormSubmit may require an email activation/confirmation for the receiving address. After activation, submissions go to the inbox.

## Important
Project links are blank in the supplied data, so project cards remain non-navigational until you add URLs as the fifth value in each project array.
